# BodyEra Fitness Website

A responsive fitness-themed front-end website developed as part of my Web Development 1 course. This project was built using HTML, CSS, and JavaScript and focuses on page structure, responsive design, navigation, product layouts, blog content, embedded media, and clean user interface design.

---

## Features

- Responsive multi-page website layout
- Custom homepage design
- Fitness product showcase page
- Blog-style content page
- Navigation menu
- Embedded media section
- Social media link integration
- Product cards with pricing and descriptions
- Branded visual design
- Beginner-friendly JavaScript functionality

---

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Screenshots
